# E-commerce orders analysis

Google Sheets project on 1,200 practice orders.

## Question
Which products and channels make profit, and do incomplete orders leak sales?

## Findings
- Highest profit products: Desk Lamp ($5,063), Wireless Earbuds ($4,789), Yoga Mat ($3,681)
- Website is the top channel on every product
- Status: 788 delivered, 211 returned, 201 cancelled (about 1 in 3 orders do not stay delivered)

## Recommendation
Grow Website listings for lamps and earbuds. Review cancel and return reasons before spending more on social ads.
